# 正式美術素材交付清單

目前專案已接入八張 WebP 聲音牌；其他品牌、背景與動態素材仍使用 CSS 幾何線條或內嵌 SVG。後續素材可依下列優先順序補充，不必一次全部完成。

## 先給這些（P0）

### 1. 品牌標誌

| 項目 | 建議檔名 | 格式 | 建議規格 |
|---|---|---|---|
| 完整 Logo（圖標＋Voice Arcana） | `brand-logo.svg` | SVG | 橫式、深色背景使用 |
| 單獨圖標 | `brand-mark.svg` | SVG | 正方形 viewBox，可做 favicon |

要求：文字若使用特殊字型，請轉外框；線條色盡量可由 CSS 控制，或另附金色版。

### 2. 八張聲音牌主插畫

| 牌名 | 建議檔名 |
|---|---|
| 留白者 | `card-blank-keeper.webp` |
| 點火者 | `card-fire-starter.webp` |
| 傾聽者 | `card-listener.webp` |
| 旅行者 | `card-traveler.webp` |
| 築夢者 | `card-dream-builder.webp` |
| 守夜人 | `card-night-keeper.webp` |
| 迴響者 | `card-echo-bearer.webp` |
| 破浪者 | `card-wave-breaker.webp` |

建議規格：

- 直式比例 `2:3`，原始尺寸至少 `1600 × 2400 px`。
- WebP，quality 85–92；每張建議小於 700 KB。
- 插畫內不要放牌名、序號與長文字，這些由網頁疊加，方便響應式與多語系。
- 主體放在中央 70% 安全區，四周保留牌框與裁切空間。
- 若插畫需要露出背景，直接做完整不透明圖；若只交付人物/圖騰，改用透明 PNG。
- 八張牌的光源、描邊粗細、金色與黑位請保持一致。

### 3. 全站背景質感

| 項目 | 建議檔名 | 格式 | 建議規格 |
|---|---|---|---|
| 深青紙張/顆粒紋理 | `texture-paper-dark.webp` | WebP | 2048 × 2048，可無縫重複 |
| 金屬箔/微光紋理（選配） | `texture-gold.webp` | WebP | 1024 × 1024，可無縫重複 |

要求：對比要低，避免壓過文字；不可內含 Logo、水印或大面積固定構圖。

## 第二批再給（P1）

### 4. 首頁主視覺

| 項目 | 建議檔名 | 格式 | 建議規格 |
|---|---|---|---|
| 桌面首屏裝飾 | `hero-ornament-desktop.svg` | SVG | 建議 viewBox 1600 × 760 |
| 手機首屏裝飾 | `hero-ornament-mobile.svg` | SVG | 建議 viewBox 390 × 700 |

內容以幾何框線、扇形、聲波、放射線為主。主標題區需保留乾淨空間，不要把可讀文字畫進素材。

### 5. 錄音區裝飾

| 項目 | 建議檔名 | 格式 | 建議規格 |
|---|---|---|---|
| 錄音面板角花 | `recorder-corners.svg` | SVG | 可四角鏡像或單一完整框 |
| 麥克風/聲音圖騰 | `recording-sigil.svg` | SVG | 正方形 viewBox |

即時波形由程式產生，不需要提供波形影片或圖檔。

### 6. 分析進度圖騰

| 項目 | 建議檔名 | 格式 | 建議規格 |
|---|---|---|---|
| 分析核心圖騰 | `analysis-sigil.svg` | 分層 SVG | 600 × 600 viewBox |

若希望網頁製作旋轉/呼吸動畫，請把外圈、中圈、中心圖騰分成有 `id` 的 `<g>` 群組。不要先輸出成影片。

## 最後再考慮（P2）

### 7. 八張牌動畫

優先順序：

1. 可由 CSS 操作的分層 SVG。
2. Lottie JSON（需同時確認授權與 runtime 體積）。
3. 透明 WebM。

不建議 GIF。每張動畫建議 2–4 秒無縫循環、檔案小於 1 MB，且要另交付靜態 fallback。

### 8. 社群分享圖與結果卡外框

本機 PNG 匯出已使用 Canvas 版面實作；若要替換為正式美術外框，再提供：

- `share-frame-portrait.svg`：1080 × 1350。
- `share-frame-story.svg`：1080 × 1920。
- 裝飾不得佔用牌名、六軸數值與隱私聲明的安全區。

## 色彩與字型資料

交付美術時也請附上：

- 主背景、次背景、金色、亮金、珊瑚紅、正文與次要文字的 HEX 色碼。
- 金色是否是純色、漸層或紋理，以及漸層角度/色標。
- 中文標題、中文內文、英數標籤的字型名稱與合法網頁授權。
- 若字型不可嵌入網頁，提供可接受的系統字型替代。

## 資料夾放置方式

```text
public/assets/art/
├─ brand/
├─ cards/
├─ textures/
├─ ornaments/
└─ motion/
```

檔名請使用小寫英文與連字號，不使用空白或中文。正式接入前，可以先把任意一張牌與 Logo 放入對應位置做版面測試。

## 交付時請一起回答

1. 哪些素材允許裁切，哪些必須完整顯示？
2. 每張牌是否有自己固定的 accent 色？
3. 手機版可以隱藏哪些裝飾？
4. SVG 是否允許程式改色、分層動畫？
5. 素材是否可用於公開網站、展覽截圖與社群分享？
6. 是否需要標註作者或授權來源？

## 專案目前的處理

- `src/ui/card-art.js`：載入八張 WebP 牌圖，並由 HTML 疊加坡框、序號、牌名與標語。
- `src/styles/`：深青背景、金色線條與幾何裝飾佔位。
- 沒有呼叫圖像生成服務，也沒有新增大型美術依賴。
- 後續替換圖片時維持既有檔名與 2:3 比例，不改動錄音和分析 domain。
