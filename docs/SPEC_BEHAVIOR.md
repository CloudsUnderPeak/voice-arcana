## 1. 產品定位與範圍

讓使用者朗讀約一分鐘的文字，在不離開裝置的前提下，把聲音的明暗、質地、節奏與能量轉譯成一張原創「聲音牌」。

核心價值：**安全感**（不上傳、不建帳號）、**被看見的感受**（抽象音色變成易懂且有美感的肖像）、**可分享的儀式感**（牌面、牌意與提問構成短而完整的體驗）、**誠實的詮釋**（清楚說明聲學代理值與限制，不假裝是人格或健康判讀）。

目標使用者：對聲音、敘事、互動藝術與自我觀察有興趣的一般使用者；需要展演互動作品的策展與設計團隊；想理解 browser-only audio pipeline 的前端開發者。**不服務**專業語音治療、醫療診斷、說話者辨識或聲紋身分驗證。

MVP 範圍：50–60 秒朗讀文章（雙語）、錄音權限與狀態流程（最短 2 秒、最長 60 秒、試聽）、六軸聲音肖像、八張牌與核心提問、桌面與手機響應式介面。**不包含**：後端、會員、歷史紀錄、雲端同步、直接串接社群平台；語音轉文字、內容理解、情緒辨識、人格判斷；可識別使用者的 voiceprint / biometric 模型；原生 App 或離線 PWA。

體驗漏斗：

```text
理解隱私與體驗目的
  → 閱讀文章
  → 主動允許麥克風
  → 錄音並試聽
  → 送出到本機分析
  → 看見聲音牌與六軸肖像
  → 展開牌意與提問
  → 選擇再錄一次或分享
```

## 2. 首頁與導讀

- 桌面寬畫面優先限制在單一 viewport；寬度 1100px 以下允許自然的垂直捲動，避免為了塞入單一畫面而裁掉內容。
- 平板與手機不得出現水平捲動；主要內容、錄音控制、牌面與六軸結果必須依序完整顯示。
- 首屏說明體驗目的與「僅在此裝置分析」承諾。
- 使用者不需登入或輸入個人資料。
- 朗讀文章主題為裝飾藝術，正常語速約 50–60 秒。
- 頁面在請求麥克風前呈現完整文章，使用者可先閱讀。

## 3. 錄音狀態

| 狀態 | 畫面 | 可用操作 |
|---|---|---|
| idle | 只顯示主要「開始錄音」按鈕 | 開始錄音 |
| requesting | 同一主按鈕顯示等待權限並停用 | 等待瀏覽器 |
| recording | 計時、分段音量強度計、結束錄音 | 手動結束 |
| validating | 顯示正在確認錄音並停用操作 | 等待本機解碼 |
| ready | 試聽、重新錄製、送出 | 重錄或分析 |
| error | 可理解的錯誤訊息 | 修正後重試 |

- 點擊「開始錄音」才呼叫 `getUserMedia`。
- 計時、音量強度計與試聽只在對應狀態出現，不在 idle 狀態預留大面板。
- 即時音量以發光圓點、18 段連續填充強度條和文字級別呈現；強度採較快上升、較慢回落的平滑變化，避免瞬時音量造成閃爍。此回饋只用於錄音操作，不直接成為分析分數。
- 最短有效錄音為 2 秒；不足時回到 idle 並顯示原因。
- 60 秒到達時自動停止。
- 錄音停止後先在本機確認 Blob 非空且可解碼；失敗時撤銷 URL、回到 idle 並提示重錄。
- ready 狀態以專案視覺語言一致的自訂控制列試聽，提供播放／暫停、時間、進度拖曳與靜音；底層仍使用本機 `<audio>`，不產生網路請求。
- 錄音訊號近乎靜音時顯示品質提示，但不阻擋使用者繼續分析。
- 試聽載入失敗時顯示可理解的錯誤、停用分析，並保留重新錄製操作。
- 重新錄製會撤銷舊的 Object URL 並清除本次結果。

## 4. 分析進度

- 送出後進入獨立進度頁，清楚重申資料沒有離開裝置。
- 進度文字依序涵蓋波形、音色、節奏/能量與聲音牌。
- 進度對應真實管線階段，但為了可感知的轉場可加入短暫最小展示時間。
- 分析失敗時回到錄音頁，保留可試聽錄音，允許再次送出或重錄。

## 5. 結果

- 六軸下方顯示該牌專屬的「聲音敘述」（cards.*.profile）：每張牌一段固定敘述文，側寫會翻出這張牌的聲音聽感，並連結牌的意涵。文案存於語系字典，只描述聲音的表現與效果，不得寫成人格或身分側寫。
- 顯示一張聲音牌，包含牌名、序號、標語與插畫。
- 六個軸都顯示左右端詞、位置與 0–100 分數。
- 結果只保留牌面、六軸肖像、聲音敘述、核心提問、分享結果與重新錄製；頁面與分享圖都不顯示創意詮釋聲明，聲明保留在 README 的產品邊界與首頁隱私說明。
- 必須顯示以下等義聲明：
  - 錄音未離開裝置。
  - 結果是本次錄音的創意詮釋。
  - 不代表人格、身分、情緒或健康診斷。
- 「再錄一次」清除錄音與結果並回到導讀頁。
- 結果內容因語言、字級或視窗高度超出單一 viewport 時，頁面必須提供垂直捲動，確保分享與重新錄製按鈕皆可到達並操作。
- 結果頁先在瀏覽器本機產生 1080 × 1350 PNG；圖片包含牌面、牌名、六軸、該牌的聲音敘述與核心提問，不包含原始音訊。
- 裝置支援檔案型 Web Share API 時，「分享結果」開啟系統分享面板；使用者取消分享時安靜返回結果頁，不視為錯誤。
- 裝置不支援檔案型 Web Share API 時，主要操作改為「下載圖片」並直接下載 PNG。
- 產圖期間按鈕顯示準備狀態並停用；分享、下載或失敗狀態以 `role="status"` 回報，不跳離結果頁。

## 6. 錯誤與邊界情境

- API 不支援：建議最新版 Chrome、Edge、Firefox 或 Safari。
- 權限拒絕：說明需允許麥克風，但不自動重複彈出權限。
- 找不到裝置：提示連接或檢查麥克風。
- 音訊無法解碼：撤銷無效錄音 URL、回到 idle 並提供重錄路徑。
- 分析到低有效語音比例：MVP 仍產生結果並標記低 confidence；M1 改為先提示品質。

## 7. 無障礙

- 所有主要控制可用鍵盤操作並有可見 focus。
- 進度列使用 `role="progressbar"` 與更新後的 `aria-valuenow`。
- 裝飾 SVG 對輔助科技隱藏；結果牌面有可理解替代文字。
- 不只用顏色表達錄音或進度狀態。
- `prefers-reduced-motion` 時停用非必要動態。

## 8. 語言

- 介面支援繁體中文（預設）與英文，全部文案（含朗讀文章、八張牌文案、六軸標籤、錯誤訊息、分享圖與分享頁 OG 文案）都有兩個語系版本。
- 語言偵測順序：URL `?lang=` 參數 → 瀏覽器 `navigator.language`（zh 系 → 中文，其餘 → 英文）。
- 頁首提供語言切換鈕，切換立即以同一狀態重繪，錄音與結果不受影響。
- 語言只存在記憶體與 URL 參數，不寫入 localStorage；重新整理與分享連結靠 `?lang=` 延續語言。
- 英文介面的分享連結指向英文分享頁（`share/en/<id>/`），社群預覽文案與開啟後的介面語言一致。
- 朗讀文章非逐句翻譯，兩個語系各自是一篇約 50–60 秒、主題相同（裝飾藝術）的可朗讀短文。

## 9. 視覺與互動系統

### Token

主要 token 定義於 `src/styles/tokens.css`：

- `--ink-950` / `--ink-900`：深梅黑背景層級。
- `--paper` / `--paper-soft`：主要與次要文字。
- `--gold` / `--gold-bright`：玫瑰銅線條、刻度、品牌。
- `--coral`：蜜桃珊瑚關鍵狀態與結果牌名。
- `--line` / `--line-soft`：框線層級。
- `--serif`：敘事、標題、牌意。
- `--sans`：控制、數據、輔助資訊。

不依賴遠端字型，避免第三方請求與字型載入造成的版面跳動。

### 元件

- **Site header**：品牌與目前體驗脈絡；本機隱私承諾保留在首屏內容和結果頁，不在頁首重複。
- **Reading card**：文章、主題、預估朗讀時間。
- **Recorder panel**：idle 只保留主要錄音按鈕；錄音中顯示計時、發光圓點、18 段強度條與文字級別；完成後顯示試聽與分析操作。
- **Processing sigil**：本機分析的等待回饋。
- **Voice card**：使用 `public/assets/art/cards/` 的八張 2:3 WebP，牌名與序號由 HTML 疊字；簡易本機 server 無法解析公開素材路徑時改讀 `public/` 原始路徑。
- **Portrait axis**：左右語意、七段刻度、菱形位置、數字分數。
- **Result question**：每張牌只保留一個核心提問與簡短限制聲明。

### 動態

- 錄音強度計只反映即時 RMS 的感知映射，不保存波形或強度資料；畫面採較快上升、較慢回落的時間平滑與連續填格過渡，避免門檻附近反覆閃爍。
- 分析頁使用三層同心圓呼吸與進度線。
- 結果六軸依序展開，建立被「描繪」的感受。
- 牌面使用八張獨立靜態 WebP；M3 再為牌框、文字與光線建立獨立動態。
- `prefers-reduced-motion: reduce` 時所有非必要動態近乎立即完成。

### 響應式

- `> 1100px`：完整三欄 header、結果左右分欄。
- `<= 1100px`：隱藏次要導覽；首屏以左側介紹、右側牌組示意排列，朗讀卡與結果則在下方滿寬呈現，允許垂直捲動。
- `<= 820px`：縮短頁首，但仍保留平板的正常字級、間距與完整內容。
- `<= 560px`：以可讀的單欄自然捲動呈現；朗讀文章、結果敘述與提問不得為塞入單一 viewport 而縮小或隱藏，主要控制滿寬堆疊。

## 10. MVP 驗收清單

1. 使用者可完成 2–60 秒錄音並試聽。
2. 送出後不產生任何聲音資料網路請求。
3. 分析可生成六個有限的 0–100 分數。
4. 結果必定對應八張既定牌之一。
5. 手機 390px 不出現水平捲動，主要按鈕可操作。
6. 重新錄製後舊錄音 URL 被撤銷。
7. 支援的手機可透過系統面板分享 PNG；其他瀏覽器可下載 PNG。產圖過程沒有資料外傳。
